KURUI v0.0.7 - Custom Minimal Launcher for TRIMUI Model S (Powkiddy A66)

[Installation Method 1: Instant Launch via TRIMUI FILE Menu (Recommended)]
1. Copy 'trimui_kurui.zip' (for FW 0.106+) or 'TrimuiUpdate_kurui.zip' (for FW <= 0.105) onto your MicroSD card.
2. On TRIMUI, open the FILE menu and execute the zip file.
3. KURUI will launch instantly on your screen!

[Installation Method 2: Manual Setup]
1. Place 'Apps/kurui/kurui' into /mnt/SDCARD/Apps/kurui/kurui
2. Place 'trimui_init.sh' directly into /mnt/SDCARD/trimui_init.sh
